# ENGR-202 Systems Engineering Project — Group 4

**Public Transit Improvement: Creating Cleaner Alternatives to the Bay Area's Reliance on Single Occupancy Vehicles**

System solution: **Bay Area Electric/Hybrid Bus System (BEHBS)** — a clean-propulsion transit-bus fleet with unified real-time scheduling, integrated fare payment, and reliable connections to existing trunk transit (BART, Caltrain, AC Transit, SFMTA, Golden Gate Transit). Two fleet alternatives are evaluated: a **battery-electric bus (BEB)** fleet and a **diesel-hybrid bus** fleet. The battery-electric alternative aligns with California's Innovative Clean Transit (ICT) zero-emission mandate.
